# VexCoreAI landing draft

Reading this as a temporary landing page for people visiting the VexCoreAI domain, with an experimental typographic direction. Dials: ENERGY 3 / RHYTHM 3 / MOTION 1.

- Palette: warm paper (`#f3efe3`) and ink (`#171915`) keep the page readable; dark red (`#a5331d`) marks the real in-progress status and one part of the wordmark.
- Theme: the fixed light palette gives this one-page poster a consistent paper-like identity; this is a public landing page, not an app with user-selectable workspaces.
- Type: Impact gives the name a compressed poster voice; system sans keeps supporting copy familiar and avoids loading a remote font.
- Layout: split the supplied name across two oversized lines, then set the status and the only action in an offset lower band. The asymmetry carries the requested experimental tone without inventing product details.
- Motion: hover and active feedback only, so movement responds to a visitor rather than competing with the message.
- Content: the product and audience are not specified, so the page states only that the site is being prepared and links to the real GitHub organization.
