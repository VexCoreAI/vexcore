# VexCoreAI landing draft

Reading this as a temporary landing page for visitors meeting the VexCoreAI name, with an experimental typographic direction. Dials: ENERGY 3 / RHYTHM 3 / MOTION 1.

- Palette: warm paper (`#f3efe3`) and ink (`#171915`) keep the page readable; dark red (`#a5331d`) marks the in-progress status and interactive focus or hover states.
- Theme: the fixed light palette gives this one-page poster a consistent paper-like identity; this is a public landing page, not an app with user-selectable workspaces.
- Type: Impact gives the name a compressed poster voice; system sans keeps supporting copy familiar and avoids loading a remote font.
- Layout: keep the supplied name on one oversized line, then set the status and the only action in an offset lower band. The asymmetry carries the requested experimental tone without inventing product details.
- Motion: hover and active feedback only, so movement responds to a visitor rather than competing with the message.
- Content: the product and audience are not specified, so the English copy stays limited to the page's in-progress status and a real GitHub destination.
